# src/lib

파싱·분석 로직. 모두 React에 의존하지 않는 순수 함수이며, 컴포넌트는 여기 결과를 받아 표시만 한다. 새 통계·집계는 컴포넌트가 아니라 여기에 추가한다.

## parse.ts

`parseFile`은 워크북의 각 시트를 두 가지 형태를 가진 `Sheet`로 변환한다.

- `rows` — 헤더를 키로 하는 객체 배열. `defval: null`이라 모든 행이 모든 열 키를 같은 순서로 가진다 (`columns`는 첫 행의 키에서 뽑는다).
- `grid` — 헤더 해석 전 원본 2차원 배열. 양식 감지(`form.ts`)용.

셀 타입은 `Cell = string | number | boolean | Date | null` (`cellDates: true`로 날짜는 `Date`). 여러 파일을 올리면 `name`이 `"파일명 · 시트명"`이 된다. `downloadSheet`는 `{ columns, rows }`를 xlsx로 내보낸다.

## analyze.ts

`analyze(sheet)` → `Analysis`: 열별 `ColumnProfile`, 빈 셀 수, 중복 행 수, 숫자 열 쌍의 상관계수, 한국어 `insights`.

- `ColumnProfile`은 `type`(`number | date | text | boolean | empty`) 기준 판별 유니온이다. 새 필드는 해당 타입의 인터페이스에 추가하고, 사용하는 쪽에서는 `type`으로 좁혀서 접근한다.
- **타입 감지**: 비어 있지 않은 값(`isMissing`이 아닌 값) 중 90% 이상이 해당 타입이면 그 타입. 판별 순서는 Date → boolean → number.
- **`toNumber`**: `"1,234"`, `"₩5,000"`, `"12%"`(→ 0.12)를 숫자로 인식한다. 0으로 시작하거나(`010...`) 숫자-숫자 하이픈이 있는 값(전화번호, 사번 등)은 의도적으로 숫자에서 제외한다.
- **`toBoolean`**: `TRUE_WORDS` / `FALSE_WORDS`의 한/영 표현(O/X, ㅇ, 예/아니오, y/n 등)을 인식한다. 인식 단어를 늘릴 때는 이 두 배열만 고친다.
- **식별자 열**: text 열에서 값이 3개 이상이고 모두 서로 다르면 `isIdentifier` (이름·연락처·ID·자유기입). 인사이트와 그룹 기준 후보에서 제외된다.
- **이상치**: IQR 1.5배 기준. 상관계수는 두 열 모두 숫자인 행이 5개 이상일 때만 계산한다.
- **인사이트 문장**(`buildInsights`): 첫 줄은 항상 전체 크기 요약이다 (양식 모드에서 `slice(1)`로 이 줄을 `formInsights`로 대체하므로 순서를 바꾸지 말 것). 열 이름 뒤 조사는 받침을 판별하지 않고 `은(는)`, `와(과)` 형태로 쓴다. 평균-중앙값 치우침은 ±0.2σ, 강한 상관관계는 |r| ≥ 0.7(최대 5개).
- **포맷터**: `formatNumber`(ko-KR, 100 이상은 소수점 없음, 아주 크거나 작으면 지수 표기), `formatDate`(로컬 날짜 기준 — `toISOString`은 UTC라 KST 자정이 전날로 밀림), `formatCell`. 화면에 값을 표시할 때는 항상 이 함수들을 쓴다.
- **`groupBy`**: 빈 값은 `'(비어 있음)'` 그룹으로 모으고, 값 열이 없으면 행 개수를 센다. 결과는 값 내림차순.

## form.ts

세로형 "항목 | 내용" 신청서 양식 시트를 처리한다.

- `toFormEntries(grid)` — 값이 있는 앞의 두 열을 항목/값으로 해석한다. 첫 행의 라벨이 `항목`·`구분`·`질문` 등이거나, 값 칸 전체가 `내용`·`작성 내용`·`답변란` 같은 헤더 문구면 건너뛴다 (부분 일치로 바꾸면 "답변 대기 중" 같은 실제 첫 항목이 사라진다). 양식이 아닌 시트에도 강제로 적용할 수 있다 (사용자가 "양식으로 보기"를 누른 경우).
- `looksLikeForm(grid)` — 값이 있는 열이 정확히 2개, 항목 2~50개, 라벨이 서로 다르고 숫자가 아니면 양식으로 본다.
- `mergeForms` — 여러 양식을 1양식 = 1행인 표로 합친다. 첫 열은 `FILE_COLUMN`(`'파일명'`), 이후 열 순서는 라벨이 처음 나온 순서. 양식에 `파일명` 항목이 있으면 `파일명 (항목)` 열로 바꿔 실제 파일명을 덮어쓰지 않는다. 합친 표는 일반 `analyze`를 그대로 거친다.
- `freeTextColumns` — 라벨에 `기타/참고/의견/비고/메모/요청` 등이 있거나 평균 15자 이상인 열을 자유기입으로 본다.
- `completionRates` / `formInsights` — 항목별 작성률과 양식 전용 요약 문장.
